# Module BRDs

One file per module, named `NN-<module>.md`, created from `_TEMPLATE.md`. `00-product-overview.md` holds the
module map.

- Read the BRD before building in a module; update it in the same change.
- State business purpose, current state and what is still needed. Link to code, don't paste it.
- Record non-obvious decisions as ADRs in `../decisions/` and link them here.
